작업 추가하기
›
1
상단 오른쪽 + 추가 버튼 탭
2
날짜 선택 (입항일 = 작업일)
3
선박명 입력 시 자동완성 목록 표시. 선택하면 선사, 엔진 정보 자동 입력
4
장소, 작업 내용, 하가일정, 청구 여부, 비고 입력
5
✅ 일정 추가 버튼 탭하면 즉시 저장
💡 선박 마스터에 등록된 선박을 선택하면 메인엔진, 발전기 모델/GOV가 자동으로 채워집니다.

작업 수정 / 삭제
›
1
카드 우측 ✏️ 버튼 탭 → 수정 화면 열림
2
내용 수정 후 💾 수정 저장 탭
3
삭제는 카드 우측 🗑 버튼 탭 → 확인 팝업 후 삭제
💡 수정 시 청구 여부도 함께 변경할 수 있습니다. (청구대기 / 청구완료)

선박 관리
›
1
상단 🚢 선박 버튼 탭
2

3

4
수정 화면 하단 KOSWEC 선박조회 → 내항/외항 확인
VesselFinder → IMO 번호 확인
5
+ 등록 버튼으로 새 선박 추가 가능

자주 묻는 질문
›
Q. 데이터가 안 보여요
새로고침(Ctrl+Shift+R) 해보세요. 인터넷 연결이 필요합니다.
Q. 추가한 데이터가 사라졌어요
Firebase 실시간 동기화로 저장됩니다. 새로고침하면 다시 나타납니다.
Q. 선박 마스터와 작업 기록의 차이가 뭔가요?
선박 마스터 - 선박의 고정 정보 (IMO, 내항/외항, 엔진 모델 등)
작업 기록 - 매 작업의 날짜, 장소, 작업 내용 등
Q. IMO 번호는 어디서 확인하나요?
선박 관리 → 해당 선박 탭 → VesselFinder 버튼으로 확인 후 입력하세요.
Q. 카카오톡 공유가 안 돼요
카카오톡 앱이 설치되어 있어야 합니다. PC에서는 작동하지 않을 수 있습니다. 모바일에서 사용해주세요.
